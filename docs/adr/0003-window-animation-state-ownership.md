# Our module owns each window animation's state

A window animation's state lives in our window animation module for its whole life, from the opening through any movement to the end of its close. Hyprland's per-window transformer and the close drawing only hold a handle to it. Each Style keeps its own states in a pool inside its runtime-owned resources. A handle is a slot index plus a generation counter, so a stale handle reads as gone and never reaches the slot's next occupant. Our module decides when an entry ends: when its Style reports it settled, when the window stops being eligible (fullscreen, unmap), when its close finishes, or when the existing clearing rules apply (reload, close disabled, monitor removal or scale change). If Hyprland drops our transformer for its own housekeeping, the entry survives and a transformer is re-attached on the next draw.

When an opening drives the window box, Hyprland's geometry warp also overwrites
its reported goal. Keep the layout goal separate from the last presented box.
Replace it only when Hyprland reports a different goal, and derive the resting
capture from that layout goal so the opening still lands at full size.

A renderer callback can end a close while its Style is still drawing. The module invalidates the handle immediately, but releases the Style state and visual buffers only after the last draw borrowing them returns. A queued close rechecks the fadeout identity and suppression at submission; it cannot draw a replacement that reused the same slot.

On a plane with a plugin-owned or suppressed close, Hyprimate handles native siblings individually, even beyond the inline batch capacity. It prepares each close's content before submitting dim or blur. If an optional effect cannot be allocated, the authorized content can still draw; no pass already handed to the renderer is replayed. A persistent content allocation failure skips that close, not its siblings.

Hyprland's nested window pass already captures client surfaces and window decorations before transformation. A backdrop effect that must sample in the parent pass can hand off its finished window-owned underlay to that same nested source. The parent and nested passes are paired for one presentation: the underlay is drawn beneath the client, then follows the style's transform, clip and stacking in one draw. Scene-global layers, popups and overlays do not participate. This live handoff is not used for captured or mirrored outputs or external shader inputs: a sampled backdrop may contain protected desktop pixels. The legacy Hyprglass adapter also leaves rotated and flipped outputs on its native path because its scissor uses output coordinates. Close effects still use the native fadeout snapshot and can only animate the paint that snapshot contains.

Cloth transition playbacks can share a recording, but each owns its displayed pose and clock. Switching to fallback releases that playback’s lease; it does not stop a recording another playback still needs. A movement copy keeps the displayed snapshots, not the worker: only the producer can post another target. Both a retained pose and a fallback pose remain valid for drawing and for a close that interrupts them.

Cloth resources acquire their worker-registry owner lazily, only for a valid open, close, or movement admission. The owner survives clearing the animation pool and is destroyed after its slots; independently retained transition playbacks may still hold their recordings after registry shutdown. Failed owner construction leaves the next admission free to retry.

We rejected keeping the state in the transformer and copying it into the close renderer when the window closes. That gave the state two homes. It copied up to 56.6 KB on every close, because the old `std::variant` reserved bubble's size for every window. A close continued from the window's current state only when that state happened to be active. And every frame looked the transformer up 3 to 4 times per window. The cost of our choice is a lifetime contract with Hyprland's transformer, which the rules above define.
